# Dataset layout

Download sources:

- **iCartoonFace** (detection subset): `bash scripts/download_icartoonface.sh`
  fetches the official Google Drive release (~4 GB) and arranges it here
  automatically. Manual links: https://github.com/luxiangju-PersonAI/iCartoonFace
- **WIDER Face**: `bash scripts/download_widerface.sh` fetches the training
  images and the official bbox annotations into place.
  Manual link: http://shuoyang1213.me/WIDERFACE/
- **film**: internal annotation set (2,458 frames / 3,700 faces from 100
  animated films); this data is not for public release
